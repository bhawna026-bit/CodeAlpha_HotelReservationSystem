# Hotel Reservation System

## Project Description
Hotel Reservation System is a Java-based application that helps users manage hotel room reservations. It allows users to view room details, book rooms, and manage customer reservations.

## Features
- View available rooms
- Book a room
- Customer details management
- Reservation management
- Display booking information

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections (if used)

## How to Run the Project
1. Download or clone this repository.
2. Open the project in VS Code/Eclipse/IntelliJ IDEA.
3. Compile and run HotelReservationSystem.java.
